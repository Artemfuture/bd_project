# Деканат: достижения студентов и рейтинг

Веб-приложение для курсового проекта по базам данных. Студент вносит достижения (участие в мероприятии, научная публикация,
членство в организации) и прикладывает документ, сотрудник деканата проверяет и подтверждает.
Баллы и рейтинг считает сама база PostgreSQL (функции и триггеры), приложение только вызывает их и показывает результат.

Стек: Python, FastAPI, PostgreSQL, интерфейс на чистом JavaScript без сборки.
Документ домашнего задания (модели и схема БД): [docs/homework.docx](docs/homework.docx).

## Запуск

Нужны Python 3.11+ и PostgreSQL 13+.

1. Создайте пустую базу `deanery` и загрузите в неё схему:
   ```powershell
   psql -U postgres -d deanery -f db/deanery.sql
   ```
2. Установите зависимости:
   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   ```
3. Скопируйте `.env.example` в `.env` и впишите пароль PostgreSQL в `DATABASE_URL`.
4. Добавьте демо-данные и учётные записи, затем запустите:
   ```powershell
   python -m scripts.seed_demo
   python run.py
   ```

Приложение откроется на http://127.0.0.1:8765.

**Быстрый показ без настройки:** `.\scripts\demo.ps1` сам поднимает временный PostgreSQL (порт 5544), грузит схему и данные и запускает приложение.
Остановить временную базу: `.\scripts\demo.ps1 stop`.

## Что где лежит

```
app/            бэкенд (FastAPI); app/modules/ - по файлу на раздел сайта
static/         интерфейс: index.html, shared.js, theme.css, modules/ и brand/ (логотип)
db/deanery.sql  схема базы с данными, функциями и триггерами
scripts/        seed_demo.py (демо-данные), demo.ps1 (показ одной командой)
tests/          тесты (pytest)
docs/           документ домашнего задания
```

## Правила в базе

- Подтвердить или отклонить достижение может только сотрудник деканата; для подтверждения нужен документ
  (функции `confirm_achievement`, `reject_achievement`).
- Рейтинг и места пересчитываются сами при изменении достижения (`recalculate_period_rating` и триггеры `trg_rating_*`).
- Отчисленному студенту нельзя добавить достижение; научный руководитель должен быть преподавателем; в иерархии мероприятий нет циклов.

## Тесты

```powershell
pytest
```

Тесты создают отдельную базу `deanery_test` из `db/deanery.sql`, поэтому пользователю из `DATABASE_URL` нужно право `CREATE DATABASE`.

## Ограничения

- Файлы не загружаются: документ указывается ссылкой или путём.
- Нет регистрации, смены пароля и редактирования справочников: их ведёт деканат в базе.
- Защита входа рассчитана на локальный показ, для публикации в сеть она не подходит.
